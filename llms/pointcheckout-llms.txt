# PointCheckout

> PointCheckout is a MENA-region payments and rewards platform that lets shoppers pay with reward points and miles and lets merchants accept card and rewards payments. Its developer-facing Merchant API (powered by paymennt.com) provides hosted, link, QR, and mobile checkouts, subscriptions, branches, and webhooks. Authentication is an API key + secret header pair.

## APIs
- [Merchant API (OpenAPI 3.0.1)](https://docs.pointcheckout.com/api/): Checkouts (web/link/QR/mobile), subscriptions, branches, and webhooks. Live: https://api.paymennt.com/mer/v2.0/ ; Test: https://api.test.paymennt.com/mer/v2.0/
